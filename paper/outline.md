# 课程论文结构（按当前进展更新）

暂定题目：**单 GPU 精确三角形计数的并行预处理优化**。
若之后完成GPU局部调度及有效分析，再考虑扩展为“单 GPU 精确三角形计数的并行预处理与任务调度研究”；现阶段不把未实现内容写成贡献。

摘要不编号，主文从以下第一节开始。LaTeX入口 `paper/main.tex`，分节位于 `paper/sections/`。

## 1. 问题定义

- 无向简单图、无序三元组、精确总数。
- 有向输入转换、自环/重边处理、孤立点与编号语义。
- 64位计数与实现范围。

## 2. 图预处理与精确计数流程

推荐此标题，既覆盖输入图转换，也衔接计数内核，避免把算法与计数误写为两个独立流水阶段。

- 2.1 图清洗与编号映射。
- 2.2 度数优先定向、向前邻居及唯一计数证明。
- 2.3 排序向前CSR、短表遍历与二分交集。
- 2.4 基础GPU边并行、跨步任务分配、64位两级归约。

本节描述共同计算流程和基础版，不与下一节优化细节重复。

## 3. OpenMP并行预处理优化

- 快速单线程解析与行边界分块的多线程解析。
- 线程私有输出、合并与错误处理；额外内存成本。
- 编号映射拆分单线程对照、并行映射、串行度数统计。
- 分块排序、并行归并、跨块去重与压缩。
- 保留的串行步骤与准确的优化边界。

## 4. 实验设计与评价指标

- 数据集实际n/m/T、A800与可见CPU拓扑、共享环境、工具链及源码版本。
- 已知答案/独立枚举、精确CSR、GPU边界检查和逐次核验。
- 完整计数时间起止位置、20次独立运行、中位数之比。
- 3次消融、两轮线程扫描分开；参数选择使用同一数据集的局限。
- 原始记录与聚合结果区分，不能由摘要制造误差统计。

## 5. 实验结果与分析

- 预处理热点：单次诊断只用于定位。
- 单项与组合消融：7配置×3图，每项3次。
- 线程扩展：8/16/32/64及统一32线程选择，停止于64。
- 主结果：相同GPU内核下，20次完整流程中位数加速约1.65×、3.31×、3.54×。
- 固定开销和剩余瓶颈；不将不同批次分项中位数机械相加。

## 6. 总结与后续工作

- 总结被数据支持的并行预处理完整收益。
- 共享负载、无独立调参集、主存峰值和原始统计不足。
- warp内局部调度作为后续研究；未完成前不写成结果。
