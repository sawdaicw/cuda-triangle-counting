# 课程论文提纲

工作题目：基于任务规模分级的 GPU 精确三角形计数。

1. 摘要：问题、方法、数据范围、真实结果及适用条件，实验完成后撰写。
2. 引言：不规则交集计算为何难以均匀分配，提出 RQ1 至 RQ3。
3. 相关工作：边并行、warp 协作、WeTriC、哈希交集；明确继承与差异。
4. 定义与正确性：清洗语义、度数定向、唯一计数证明。
5. 方法：CSR、工作量代理、G0/G1/G2、归约和准备成本。
6. 设置：数据、独立验证、工具链、硬件、阈值开发集、计时范围。
7. 结果：同 GPU 主比较、消融、敏感性、时间分解及重复摊销。
8. 讨论：定向后负载、失败案例、设备依赖、单 GPU 和内存限制。
9. 结论：只总结实测支持的发现。

预期表图：数据统计表、正确性表、内核与端到端性能、任务分布、阈值曲线、成本分解、R 次复用曲线。

本项目目前没有性能结果，不提前填写提升比例或首创性结论。
