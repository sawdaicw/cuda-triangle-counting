# 实验记录协议（当前口径）

本文取代最初“预热5次、测30次”的草案口径。历史实验按其实际配置记录，不改写历史采样次数。已有结果见 [阶段性结果](experiment_results.md)，汇总CSV与来源见 [results/reported](../results/reported/README.md)。

## 主比较

- 相同输入、同一物理GPU、相同输出语义，使用自己的GPU边并行基础版本作主对照。
- 本阶段比较原版主机预处理与32线程组合预处理，GPU二分交集和归约保持相同。
- 主指标 `first_total_ms` 从读取边表前，到首次GPU结果回传后；包含必要图预处理、OpenMP开销、任务准备、初始化、显存分配、传输、计算、同步和归约。
- 排除下载/解压/编译、额外CPU正确性核验、实验日志输出及程序结束释放；明确这些边界，不把必要准备工作移到计时外。
- 每版每图独立新进程运行20次，轮内交替/打乱版本顺序。报告各版总时间中位数及波动，主加速比=基础版中位数/优化版中位数。
- 本轮命令使用warmup=0、repeat=1；每进程在主计时结束后还运行一次额外内核。它不计作第二个完整样本，也不纳入主总时间。
- 未控制CPU绑核、NUMA、GPU独占或冷文件缓存；此类结果只在已记录环境下解释，不声称硬件独占条件。

## 诊断与消融

- 分项插桩仅用于定位热点，正式主比较统一关闭。
- CPU预处理探索每配置每图3次，与GPU完整时间单独记录；线程扫描不同轮次使用不同experiment_id。
- 单项配置区分快速解析本身、OpenMP并行、映射拆分成本和排序/去重成本。排序归并、数组分配、压缩和线程私有结果合并均计入。
- GPU计数调度若后续实现，计数基线和优化版使用相同预处理，归约及任何筛选准备不能漏计。
- 同一预处理结果复用R次时，另开实验并报告 `Tprep + Σ Texec`，不可把复用内核时间当一次完整任务时间。

## 正确性与元数据

- 小图使用已知计数或独立枚举；不同预处理生成的CSR要逐项一致；真实图GPU结果与相同图的独立CPU交集实现一致。
- 记录输入来源/哈希、清洗规则、n/m、精确计数、源码SHA和未提交差异、编译器及参数、GPU型号/UUID/驱动、CPU拓扑/可用核/负载、实际OpenMP线程、亲和性/NUMA策略、启动配置。
- 保存每次完整JSON、命令、stderr和状态，不以摘要替代原始记录。OOM、失败、超时及没有加速的样本如实保留；异常处理规则如需设定，应先声明。
- 归档前核对metadata中的代码版本、二进制和输入身份；从压缩包运行时保留SOURCE_COMMIT。
- 当前仓库reported目录只有用户提供的汇总，不含全部逐次JSON。没有原始数据就不生成方差、箱线图、置信区间或显著性结论。

CPU串行性能单列，不替代同GPU对照。与库或论文代码对照属于后续扩展，未完成前不写结果。
