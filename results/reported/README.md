# 已报告实验汇总

此目录保存用户在对话中提供的终端汇总与单次诊断记录，供阶段性分析和论文表格使用。**不是逐次原始运行数据目录，也不是助手重新运行实验的结果。** 完整来源、软硬件和已知限制见 `experiment_manifest.json`。

| 文件 | 实验内容 | 采样与指标 |
|---|---|---|
| `full_gpu_20_summary.csv` | 原版主机预处理 vs 32线程组合优化；GPU计数相同 | 每图每版20次独立完整流程，主指标 first_total_ms |
| `preprocess_ablation_3_summary.csv` | 原版、快速解析、单项并行与组合 | 每图每配置3次，只有 preprocess_ms |
| `thread_scaling_3_summary.csv` | 早期2/4/8和后续8/16/32/64线程扫描 | 各3次，两轮用不同 experiment_id，禁止混合统计 |
| `preprocess_profile_single.csv` | 原版三个图及Amazon all8的阶段诊断 | 每项只有1次，不能当重复实验中位数 |
| `historical_baseline_full20_summary.csv` | 优化前单独测量的基础版 | 历史20次汇总，不用于替代后续交替比较的同期基础版 |
| `datasets.csv` | 实际清洗后的顶点/边/三角形数 | 与报告的精确计数对应 |
| `experiment_manifest.json` | 来源、版本、环境、计时边界、限制 | 非运行原始日志 |

正式主比较共报告120个样本的聚合结果（3图×2版×20次），但相应120份逐次JSON未上传仓库。不要从中位数/min/max重建伪造样本、箱线图、标准差、四分位数、置信区间或显著性结果。等原始记录归档后再补充这些统计，并核对代码版本与输入哈希。

数据精度按用户提供内容保留。后续高线程扫描与历史基线只提供三位小数；CSV写入时不补造更高精度。消融和正式比较来自不同批次，不能把不同批次的阶段中位数直接相加做成本分解。

论文表格由 `python3 paper/generate_tables.py` 从这些CSV生成；不能只修改LaTeX表格造成与数据不一致。生成脚本检查样本数、时间范围和加速比计算。
